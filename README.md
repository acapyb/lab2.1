# Lab Exercise 2.1: HTML Elements and Attributes

## Introduction

This repository contains my work for **Lab Exercise 2.1: HTML Elements and Attributes**. The purpose of this lab is to understand the basic structure of HTML documents, explore different HTML elements, and learn how attributes are used in web development.

The lab consists of four parts: Part A, Part B, Part C, and Part D.

## Objectives

- Understand the basic structure of an HTML document.
- Identify and explain common HTML elements.
- Learn how to use HTML attributes.
- Create a basic webpage using HTML.
- Develop a personal information webpage.
- Practice using Git and GitHub for version control.

## Lab Activities

### Part A: HTML Elements

This section focuses on identifying HTML elements and understanding their functions.

The elements covered include:

- `<!DOCTYPE html>`
- `<html>`
- `<body>`
- `<p>`
- `<br>`
- `<h3>`
- `<a>`

A simple HTML page is also created to demonstrate some of these elements.

**File:** `part-a.html`

### Part B: Basic Structure of HTML

This section demonstrates the basic structure of an HTML document using:

- `<html>` to define the HTML document.
- `<head>` to contain metadata and the page title.
- `<body>` to display the webpage content.

**File:** `part-b.html`

### Part C: HTML Attributes

This section demonstrates the implementation of ten HTML attributes.

| Attribute | Description |
|---|---|
| `id` | Assigns a unique identifier to an element |
| `class` | Groups elements using a common class |
| `href` | Specifies the destination of a hyperlink |
| `src` | Specifies the source of an image |
| `alt` | Provides alternative text for an image |
| `title` | Provides additional information about an element |
| `style` | Applies inline CSS styling |
| `disabled` | Disables an input element |
| `value` | Specifies the value of an input |
| `checked` | Preselects a checkbox |

**File:** `part-c.html`

### Part D: Personal Details Webpage

This section involves creating a personal webpage containing:

- Personal heading
- Profile picture
- Full name
- Matric ID
- Year of study
- Hometown address
- A hyperlink to a tourist attraction in the hometown

**File:** `part-d.html`

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder using Visual Studio Code.
3. Place the project folder inside `C:\xampp\htdocs`.
4. Start Apache using the XAMPP Control Panel.
5. Open a web browser and visit:

   `http://localhost/lab-exercise-2-1/part-a.html`

6. Change the filename in the URL to access `part-b.html`, `part-c.html`, or `part-d.html`.

Alternatively, the HTML files can be opened directly in a browser without XAMPP.
